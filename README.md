# Task 1 - Simple URL Shortener

## Tech
- Python
- Flask
- SQLite
- HTML/CSS/JavaScript

## Run
```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

## Features
- POST API at `/api/shorten`
- Unique short codes
- SQLite database
- Redirect from short URL to original URL
- Click counter
- Simple frontend
- GET API at `/api/urls`
